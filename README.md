# DSA_Visualizer


An interactive web application built to visualize various Data Structures and Sorting Algorithms in real-time. This project helps in understanding how sorting mechanisms and data flows work under the hood through step-by-step animations.

## 🌟 Features

*Sorting Algorithms:*
* *Bubble Sort* ($O(n^2)$)
* *Selection Sort* ($O(n^2)$)
* *Insertion Sort* ($O(n^2)$)
* *Merge Sort* ($O(n \log n)$)
* *Quick Sort* ($O(n \log n)$)

*Data Structures:*
* *Stack:* LIFO (Last-In-First-Out) operations with visual Push and Pop animations handling overflow/underflow.
* *Queue:* FIFO (First-In-First-Out) operations with visual Enqueue and Dequeue animations.

*Interactive Controls:*
* Generate new random arrays on the fly.
* Adjust array size dynamically using a slider.
* Color-coded representation to identify different states (e.g., comparing, swapping, pivot selection, and fully sorted).

## 🛠️ Technologies Used
* *HTML5:* Structuring the master layout and individual visualizer pages.
* *CSS3:* Styling, Flexbox/Grid layouts, and smooth transitions.
* *Vanilla JavaScript:* Core logic, DOM Manipulation, and utilizing async/await with Promises for animation delays. No external libraries were used.
